# 卡牌设计指南

面向想给《授时局》加刻印的人。技术流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)，这里只谈数值与手感。

## 一张刻印要回答的问题

1. **它属于哪种时序形态？** 这决定了它的数值预算
2. **玩家在什么局面下会想要它？** 说不出具体局面的牌，就是没人会拿的牌
3. **它和现有牌的区别是什么？** 如果只是「同样的效果但更大」，它会让卡池变无聊

## 三种形态的数值预算

基准：标准单位每 100 行动值行动一次。

### 即时（instant）

立即结算。这是玩家的安全网，也是数值基准线。

| 费用 | 伤害 | 格挡 |
|---|---|---|
| 0 | 3–4 | 3 |
| 1 | 6–8 | 5–7 |
| 2 | 12–16 | 11–14 |
| 3 | 18–24 | 16–20 |

即时刻印可以有额外效果，但每多一条就要扣掉一部分主数值。

### 挂刻（deferred）

延迟结算。**伤害/时能必须严格高于全部即时刻印的上限**——这条由 `tests/content.test.ts` 强制，是机制存在的理由。延迟是它的价格，数值是它的报酬。

延迟不能低于 50 行动值（半次标准行动）。低于这个数，「挂刻」在实战里几乎等于立即生效，玩家看不到排序问题，机制就退化成了装饰。同样由测试强制。

| 延迟 | 相对伤害/时能 |
|---|---|
| 60 左右 | 约 2 倍即时 |
| 120 左右 | 约 2.5–3 倍即时 |
| 180 以上 | 约 3.5 倍即时 |

挂刻牌也可以不做伤害：延迟格挡、延迟抽牌、延迟治疗都成立。这类牌不参与上面那条性价比断言，但要单独想清楚「为什么玩家愿意等」。

一个值得用的手法：**给挂刻牌加一个只在结算时才知道的条件**。比如「60 行动值后，若你仍有格挡则造成双倍伤害」。这让延迟从纯代价变成了博弈。

### 校正（shift）

只操作时间轴，不造成任何伤害或格挡（由测试强制）。它是「用一张牌换排序」的交易。

| 效果 | 1 费合理量级 |
|---|---|
| 自身行动值提前 | 25–35 |
| 目标行动值推后 | 30–40 |
| 取消已排入轴的行动 | 附加推后 20–30 |
| 把挂刻提前引爆 | 40–50 |
| 步频永久 +N | 2–3（本场战斗，可叠加） |

校正牌的价值完全取决于场上有没有值得调整的时序关系。所以在只有一两个敌人的早期关卡里它们偏弱，在敌人多、行动密集时很强——这是设计意图，不是失衡。

## 命名与文本

**设定对齐**：卡牌叫「刻印」，能量叫「时能」，打出延迟牌叫「挂刻」，打断叫「校正」，遗物叫「授时器」，速度叫「步频」，生命叫「稳定度」，敌人叫「畸变体」。

**命名要有画面**：`霜击`、`并流`、`过载`、`锚定`、`打断`、`时隙` 都能一眼想出画面。避免 `攻击强化 II` 这种。

**风味文本写一句就够**，而且不要重复机制。写「迟到的霜，落在最不该落的地方」而不是「这张牌造成 14 点伤害」。

**文本里必须出现 effects 里的每个数值**，这是硬约束，内容校验会拦。写法约定：

| 效果 | 写法 |
|---|---|
| 伤害 | `造成 N 点伤害` |
| 格挡 | `获得 N 点格挡` |
| 挂刻 | `N AV 后，…` |
| 抽牌 | `抽 N 张牌` |
| 易伤 | `使目标获得 N 层易伤` |
| 虚弱 | `使目标获得 N 层虚弱` |
| 自身提前 | `自身行动值 -N` |
| 推后目标 | `使目标行动值 +N` |

数值用 ASCII 连字符 `-15`，不要用排版减号 `−15`。

## 上手自查

写完之后问自己三个问题：

1. **它在什么局面下，比现有牌更好？** 说得出具体局面才算成立
2. **它有没有让别的牌失去意义？** 一张新牌如果严格优于某张旧牌，就要么改它，要么改旧牌
3. **`npm test` 过了吗？** 数值手感靠人判断，但一致性靠测试
