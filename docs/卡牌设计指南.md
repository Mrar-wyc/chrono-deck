# 卡牌设计指南

面向想给《授时局》加刻印的人。技术流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)，这里只谈数值与手感。

## 一张刻印要回答的问题

1. **它属于哪种时序形态？** 这决定了它的数值预算
2. **玩家在什么局面下会想要它？** 说不出具体局面的牌，就是没人会拿的牌
3. **它和现有牌的区别是什么？** 如果只是「同样的效果但更大」，它会让卡池变无聊

## 三种形态的数值预算

基准：标准单位每 100 行动值行动一次。

### 即时（instant）

立即结算。这是玩家的安全网，也是数值基准线。

| 费用 | 伤害 | 格挡 | 现有实卡 |
|---|---|---|---|
| 0 | 3–4 | 3 | 测准 4 伤 / 预置 3 挡 |
| 1 | 6–8 | 5–7 | 校准 6 / 拆解 7 / 准绳 5 / 守刻 5 |
| 2 | 12–16 | 11–14 | 复核 14 / 盾墙 14 |
| 3 | 18–24 | 16–20 | （暂无实卡，留作预算） |

上表是**预算而不是普查** —— 3 费那一行目前是空的，不要照着它以为牌池已经填满。

即时刻印可以有额外效果，但每多一条就要扣掉一部分主数值。

**付费即时刻印的伤害/时能上限目前是 7**（复核 14/2 与拆解 7/1）。这个数字会被挂刻牌的不变式引用，改上面任何一张牌都要注意它。

### 挂刻（deferred）

延迟结算。**付费**挂刻牌的伤害/时能必须严格高于**付费**即时刻印的上限（现为 7）——这条由 `tests/content.test.ts` 强制，是机制存在的理由。延迟是它的价格，数值是它的报酬。

（0 费牌不参与这条比较：它的比值是无穷大，会把上限顶成 `Infinity`；0 费牌的代价是卡位与抽牌，拿它比能量效率本身就是错的口径。）

延迟不能低于 50 行动值（半次标准行动）。低于这个数，「挂刻」在实战里几乎等于立即生效，玩家看不到排序问题，机制就退化成了装饰。同样由测试强制。

| 延迟 | 相对付费即时上限（7） |
|---|---|
| 60 左右 | 约 1.7 倍（霜击 12/1、积时 12/1） |
| 90 左右 | 约 1.3–2 倍（并流 14/时能、缀霜 9/时能） |
| 120 以上 | 约 1.5–2.5 倍（回响 18/时能、蓄爆 17/时能） |

表里的区间拉开得大，是因为**带代价的牌可以低一些**：过载（3 费、30 伤、自身易伤 3 层）只有 1.43 倍，那是它为「自身变脆」付的钱。别把它当异常值去"修"。

挂刻牌也可以不做伤害：延迟格挡、延迟抽牌、延迟治疗都成立。这类牌不参与上面那条性价比断言，但要单独想清楚「为什么玩家愿意等」。

一个值得用的手法：**给挂刻牌加一个只在结算时才知道的条件**。比如「60 行动值后，若你仍有格挡则造成双倍伤害」。这让延迟从纯代价变成了博弈。

### 校正（shift）

只操作时间轴，不造成任何伤害或格挡（由测试强制）。它是「用一张牌换排序」的交易。

| 效果 | 量级 | 现有实卡 |
|---|---|---|
| 自身行动值提前 | 0 费约 15，1 费约 40 | 提前一刻 −15（0 费）、快进 −40（1 费） |
| 目标行动值推后 | 0 费约 20，2 费约 60 | 迟滞 +20（0 费）、定格 +60（2 费） |
| 取消已排入轴的行动 | 1 费附加推后 25，2 费 60 | 打断 25、截断 60 |
| 把挂刻提前引爆 | 0 费 25，2 费 60 | 锚定 25、并轨 60 |
| 步频永久 +N | 2 费 +2 | 授时 +2 |

跨度这么大是因为**大额操作只能卖高价**：把敌人推后 60 行动值足以让它整整少出一招，那不是 1 费能买到的东西。定新牌的数值时看同一列里最接近的那张，别按「1 费该给多少」一刀切。

校正牌的价值完全取决于场上有没有值得调整的时序关系。所以在只有一两个敌人的早期关卡里它们偏弱，在敌人多、行动密集时很强——这是设计意图，不是失衡。

## 命名与文本

**设定对齐**：卡牌叫「刻印」，能量叫「时能」，打出延迟牌叫「挂刻」，打断叫「校正」，遗物叫「授时器」，速度叫「步频」，生命叫「稳定度」，敌人叫「畸变体」。

**命名要有画面**：`霜击`、`并流`、`过载`、`锚定`、`打断`、`时隙` 都能一眼想出画面。避免 `攻击强化 II` 这种。

**风味文本写一句就够**，而且不要重复机制。写「迟到的霜，落在最不该落的地方」而不是「这张牌造成 14 点伤害」。

**文本里必须出现 effects 里的每个数值**，这是硬约束，内容校验会拦。写法约定：

| 效果 | 写法 |
|---|---|
| 伤害 | `造成 N 点伤害` |
| 格挡 | `获得 N 点格挡` |
| 回复 | `回复 N 点稳定度` |
| 挂刻 | `N AV 后，…` |
| 抽牌 | `抽 N 张牌` |
| 时能 | `获得 N 点时能` |
| 易伤 | `使目标获得 N 层易伤` / `并使自身获得 N 层易伤` |
| 虚弱 | `使目标获得 N 层虚弱` / `并使自身获得 N 层虚弱` |
| 自身提前 | `自身行动值 -N` |
| 推后目标 | `使目标行动值 +N` |
| 步频 | `本场战斗中步频 +N` |

数值用 ASCII 连字符 `-15`，不要用排版减号 `−15`。

## 上手自查

写完之后问自己三个问题：

1. **它在什么局面下，比现有牌更好？** 说得出具体局面才算成立
2. **它有没有让别的牌失去意义？** 一张新牌如果严格优于某张旧牌，就要么改它，要么改旧牌
3. **`npm test` 过了吗？** 数值手感靠人判断，但一致性靠测试

# 畸变体（敌人）设计

敌人的数值不是靠手感调的，是靠 `tests/balance.test.ts` 的实测胜率调的。以下三条是已经踩过的坑，加新敌人前请先读。

## 一、敌人的「操作时间轴」必须是附加手段，不能取代伤害

失序使的设定是「时间的主宰」，最初的招式表里只有一招带伤害，另外两招纯操作行动值。实测结果：胜率 98% —— 比精英还容易打。它的输出低到玩家几乎不会输，首领战成了走过场。

**规则：如果一个敌人以操作时间轴见长，那些招式也要带伤害。** 时间轴操作是它的特色，不是它的全部。

## 二、永久生效的易伤是乘算放大器，会让群战崩掉

锈蚀体最初施加 2 层易伤，每两回合刷新一次、每回合只衰减 1 层 —— 等于整场战斗永久 ×1.5。有它在场的双怪组合，所有伤害都被放大 50%，精英胜率从 40% 掉到 0%。而调低它的数值只会让单只锈蚀体变成必胜局，两头都堵。

**规则：易伤与虚弱是玩家的手段（准绳、缀霜），敌人不用它们施压。** 敌人要制造「越打越不利」的压力，用**推后玩家的行动值** —— 那是加法不是乘法，不会顺带把别的敌人一起变强，而且它逼玩家去用校正牌，正好呼应核心机制。

## 三、双怪不能是「双强」，群战档需要一种弱畸变体

玩家的每回合格挡是有限定额（3 点时能、每张守刻 5 点）。两只满编怪一回合打出的量越过他能承受的上限时，胜率会**从 100% 一步跌到 0%**，中间没有过渡 —— 这不是数值偏了，是结构问题。

**规则：群战遭遇用「强 + 弱」或双弱组合。** 碎屑体（46 血、约 8 DPS）就是为此而设的弱畸变体。

## 数值速查

| 类型 | 血量 | 单次伤害 | 说明 |
|---|---|---|---|
| 弱畸变体 | 40–50 | 8–12 | 只用于群战，单独出现时偏软 |
| 普通畸变体 | 60–100 | 14–21 | 教学局，允许接近必胜 |
| 精英（强 + 弱） | 合计 110 左右 | — | 实测胜率目标 20%–75% |
| 首领 | 180–200 | 24 左右 + 附带效果 | 实测胜率目标 10%–60% |

步频的影响不小于伤害：步频 130 的单位行动间隔是 77，比标准单位快 23%，也就是出手次数多出约三成（100/77 = 1.30）。

## 改完必须做的事

```bash
npx vitest run tests/balance.test.ts                     # 看胜率是否落在分档区间
DIAG=1 DIAG_ENCOUNTER=e_elite npx vitest run tests/diag.test.ts   # 逐回合看是哪一段崩的
```

汇总数字只告诉你「有没有问题」，看不出「问题出在哪一段」。加伤害与加血量的效果可能完全不同，而且**同一个敌人身上出现过两次方向相反的结论**：

- 早先一次：首领加伤害让胜率从 80% 一步跌到 0%，改成加血量才拿到中间档 —— 因为那场战斗是「抢在积累伤害之前打死它」的赛跑，加伤害会直接跨过阈值
- 后来一次：修好一个空转的招式之后首领的行动频率涨了约 23%，胜率从 18% 掉到 0%，那次是**下调伤害、保留节奏**才收回来的

两次的修正方向相反，靠手感猜不出来。所以改完一定要跑平衡与诊断，别只看单张牌的数字。
